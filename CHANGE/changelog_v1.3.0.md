# Release v1.3.0

本版本新增标准化 Markdown 与可读快照导出，并完善文章阅读、下载和跨平台交付体验。

## 新增功能

- 每个文档版本保存标准化 Markdown，支持在线阅读、Markdown/PDF 下载、最新文档树、任务快照以及历史版本回填。
- 文章页增加经过清理的 Markdown 渲染、本地代码高亮、响应式文章大纲、当前标题跟踪和文档备份状态。
- GitHub Release 提供 Linux amd64/arm64、Windows amd64 原生归档及 SHA256 校验文件。

## 优化改进

- worker 在成功或部分成功任务结束后维护可读导出树，并按现有保留策略清理旧快照。
- Docker 镜像补充 PDF 运行库、中文字体和独立导出数据卷；发布流程在同一 Tag 和提交的 CI 成功后才发布资产。

## Bug 修复

- 空白或仅含空白字符的语雀正文不再生成不可读的成功版本，并会记录明确问题。
- 正文选择会跳过空白候选字段并继续使用其他可用内容，避免误判为空正文。
