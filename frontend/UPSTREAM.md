The project keeps the upstream Vue 3 single-application structure, Tailwind CSS v4 theme, shadcn-vue component source, `components.json`, Vite/Vitest/TypeScript configuration model, and responsive sidebar primitives. Upstream demonstration APIs, localStorage bearer authentication, dynamic backend menus, RBAC, commerce pages, notifications, and MSW demo handlers were removed because they are outside the Yuque Backup MVP and conflict with its confirmed API contract.
