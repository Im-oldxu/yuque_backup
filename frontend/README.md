# Yuque Backup Admin

Yuque Backup 的 Vue 3 管理端，基于 `tabtab-dev/tabtab-admin` 的固定提交开发。

完整安装、环境变量、启动、测试和构建说明见项目根目录的《前端快速启动说明.md》。

常用命令：

```powershell
corepack pnpm install --frozen-lockfile
corepack pnpm dev
corepack pnpm typecheck
corepack pnpm test
corepack pnpm build
```

默认开发地址：`http://127.0.0.1:3002/#/auth`
